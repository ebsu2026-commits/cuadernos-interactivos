# Cuadernos Interactivos — Centro Educativo Salomé Ureña

Cuadernos de clase de Inglés y Francés, todos los grados que se imparten en el centro, con pronunciación pre-grabada (voz neuronal) en cada palabra y frase — funciona sin conexión a internet.

Abre [`index.html`](index.html) para ver el índice completo.

## Contenido

| Carpeta | Cuaderno |
|---|---|
| `ingles-1ro/` | Inglés · 1° de Secundaria (4 periodos) |
| `frances-1ro/` | Francés · 1° de Secundaria (4 trimestres) |
| `ingles-2do/` | Inglés · 2° de Secundaria (4 periodos) |
| `frances-2do/` | Francés · 2° de Secundaria (4 trimestres) |
| `ingles-3ro/` | Inglés · 3° de Secundaria (4 periodos) |
| `frances-3ro/` | Francés · 3° de Secundaria (4 trimestres) |
| `ingles-6to-primaria/` | Inglés · 6° de Primaria (4 periodos) |

Cada carpeta contiene los 4 cuadernos HTML del año y su carpeta `audio/` con la pronunciación. No incluye las planificaciones ni los registros de evaluación (documentos internos del centro).
